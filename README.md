# HTML Workshop

A small learning workspace for exploring and practicing HTML, CSS, and web page structure.

## Overview

This project is intended as a starter space for:

- building basic HTML pages
- experimenting with semantic elements
- styling with CSS
- adding simple interactivity with JavaScript
- learning front-end fundamentals in a clean workspace

## Getting Started

1. Open the project folder in VS Code.
2. Create or edit HTML files in the project root or subfolders.
3. Open the page in a browser to preview your changes.
4. Refresh the page after edits to see updates.

## Suggested File Structure

```text
HTML_workshop/
├── index.html
├── styles.css
├── script.js
├── assets/
│   └── images/
└── README.md
```

## Example HTML

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>HTML Workshop</title>
    <link rel="stylesheet" href="styles.css" />
  </head>
  <body>
    <h1>Hello, World!</h1>
    <p>This is a simple HTML page.</p>
    <script src="script.js"></script>
  </body>
</html>
```

## Notes

- Use semantic HTML such as `header`, `main`, `section`, and `footer`.
- Keep your CSS separate for cleaner structure and easier maintenance.
- Test your pages in a browser to check layout and responsiveness.
